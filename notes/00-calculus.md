# 00 · 微积分最小必备知识（反向传播的前置课）

> 前置阅读，服务于 [01-backpropagation](01-backpropagation.md)
> 日期：2026-10-14
> 只需要三个概念：**导数、偏导数、链式法则**。

## 1. 导数：变化有多快

导数回答的问题是：**"输入变一点点，输出会变多少？"**

比如 `f(x) = x²`，在 `x = 3` 处，x 增加 0.001，f 大约增加多少？
不用记公式，用代码就能"量"出来：

```python
f = lambda x: x ** 2

x = 3.0
h = 0.001
slope = (f(x + h) - f(x)) / h   # (9.006 - 9) / 0.001 ≈ 6.0
```

这个 `slope` 就是导数 ≈ 6。含义：**x 每动 1 个单位，f 大约动 6 个单位**（在 x=3 附近）。

> 顺便说：这种"用小 h 量一量"的办法叫**数值梯度**，后面我们会用它来
> 验证自己实现的反向传播算得对不对（gradient checking）。

需要记住的求导规则只有两条：

- **幂规则**：`xⁿ` 的导数是 `n·xⁿ⁻¹`（所以 `x²` → `2x`，`x³` → `3x²`）
- **常数**：`5` 的导数是 `0`（常数不随 x 变）；`x + 1` 的导数和 `x` 一样，都是 `1`

## 2. 偏导数：一次只看一个变量

模型有很多参数，比如 `z = x · y`。想知道 z 对 x 的敏感度时，
**把其他变量当成固定的常数**，只对 x 求导：

```
z = x · y
∂z/∂x = y    （y 当常数看，就像 4·x 的导数是 4）
∂z/∂y = x    （x 当常数看）
```

符号上，`∂`（读作 "partial"）就是"多变量情况下的导数"，和 `d` 含义一样，
只是提醒你有多个变量。

## 3. 链式法则：嵌套函数怎么办

如果函数是**套娃**：`x → z → loss`，即 `loss` 不直接依赖 `x`，
而是通过 `z` 间接依赖，那么：

```
∂loss/∂x = ∂loss/∂z × ∂z/∂x
            ↑              ↑
     "loss 对 z 多敏感" × "z 对 x 多敏感"
```

直觉理解：x 动一点点 → z 动 `∂z/∂x` 倍 → loss 又跟着动 `∂loss/∂z` 倍，
两个倍数**相乘**就是总效果。

套娃再多层也一样，一路乘下去：

```
∂loss/∂x = ∂loss/∂a × ∂a/∂b × ∂b/∂c × ∂c/∂x
```

## 串起来看

反向传播就是把这三件事组合起来：

- 模型 = 一个超多层的套娃函数，参数有上亿个
- 每个参数想知道"我对 loss 的影响" → **偏导数**
- 影响隔着很多层传过来 → **链式法则**，一层层乘回去
- 训练 = 算出所有参数的偏导数（合起来叫**梯度**），每个参数往让
  自己减小的方向挪一步（`参数 -= 学习率 × 梯度`，这叫**梯度下降**）
