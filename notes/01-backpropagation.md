# 01 · 反向传播：深度学习的心脏

> 对应阶段：0（mini 自动微分引擎）
> 日期：2026-10-12

## 一个最朴素的问题

训练一个模型，本质上就一件事：

> 模型有一堆参数（比如权重 `w`），我们要不断调整它们，让模型的预测误差（loss）越来越小。

那"怎么调"呢？答案是**梯度**：算出"如果 `w` 增加一点点，loss 会变化多少"，
然后往相反方向调。就像蒙眼下山 —— 感受脚下哪边陡，就往低处挪一步。

## 链式法则：梯度是怎么"传"回去的

模型不是一个函数，而是**一串函数的嵌套**。举个最小的例子：

```
z = x * y
loss = z + 1
```

想知道 `loss` 对 `x` 的梯度，微积分的链式法则说：

```
∂loss/∂x = ∂loss/∂z × ∂z/∂x = 1 × y = y
```

纯 Python 代码：

```python
x, y = 3.0, 4.0

# 前向传播：从输入算出 loss
z = x * y        # z = 12
loss = z + 1     # loss = 13

# 反向传播：从 loss 往回推梯度
dloss_dz = 1.0        # loss = z + 1, 所以对 z 的导数是 1
dz_dx = y             # z = x * y, 所以对 x 的导数是 y
dz_dy = x             # 对 y 的导数是 x

dloss_dx = dloss_dz * dz_dx   # = 1 * 4 = 4
dloss_dy = dloss_dz * dz_dy   # = 1 * 3 = 3
```

`dloss_dx = 4` 的含义：x 每增加 0.001，loss 大约增加 0.004。
所以训练时让 `x -= 学习率 * 4`，loss 就降下来了。

**真实模型无非是把这两行换成上亿个参数的巨型函数嵌套**，但规则一模一样：
前向时算值，反向时用链式法则一层层把梯度传回去。

## 关键洞察：可以自动化

上面的规律 —— 每个操作（`*`、`+`）只需要知道两件事：

1. **前向**：怎么算输出值
2. **反向**：输出梯度已知时，怎么算自己每个输入的梯度（局部导数 × 上游梯度）

只要为每种基本操作写好这两条规则，再把操作按顺序连成一张**计算图**，
梯度就能自动从末端一路传回起点。这就是 PyTorch `loss.backward()` 背后做的事，
也是阶段 0 要亲手实现的东西：

```python
# 我们最终要做出这样的效果：
x = Tensor(3.0)
y = Tensor(4.0)
loss = x * y + 1
loss.backward()   # 自动算出 x.grad == 4, y.grad == 3
```

## 小结

- 训练 = 反复调整参数让 loss 变小
- 怎么调 = 看梯度（导数），反方向走
- 梯度怎么算 = 链式法则，从 loss 一层层往回传
- 每个基本操作写好"前向 + 反向"规则，就能自动化 → 这就是 autograd
